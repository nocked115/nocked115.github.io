02 · Approach3단계 파이프라인

성격이 다른 두 점수를 합치고, 합치는 비율 α와 판정 임계값을 모두 검증셋으로 고릅니다.

STEP 1

CAE 재구성

정상 영상만으로 학습한 Convolutional AE의 픽셀 재구성 오차.

image score = spatial mean checkpoint = best val AUROC
STEP 2

특징 거리 (PaDiM)

ImageNet ResNet-18 layer1–3 특징의 위치별 가우시안과의 거리.

448ch → 100ch (random) Mahalanobis², Σ + 0.01·I
STEP 3

융합 + 임계값

두 점수를 검증셋 min-max로 정규화해 가중합, 임계값은 검증 F1 최대.

S = α·S′rec + (1−α)·S′feat α ∈ {0.0, 0.1, …, 1.0}

내가 한 일

  • Liver CT 전처리 파이프라인 (BTCV + LiTS, BMAD 공식 split), CAE 학습과 best checkpoint 선정
  • ResNet-18 PaDiM 특징 추출기 (layer1–3 concat, 차원 축소, squared Mahalanobis distance)
  • 점수 융합 · α grid search · Adaptive / Fixed / Quantile 임계값 비교, Backbone 비교 (ResNet-34 · 50 · WideResNet-50)
  • 지도교수 Q&A 7건 답변, 논문–코드 불일치 4건 수정, Table · 초록 · 결론 수치 일관성 전수 확인

03 · Result결과

FINDING 01

도메인마다 최적 α가 다르다

α* = 0.30 / 0.90 / 0.00. 재구성과 특징 정보가 얼마나 쓸모 있는지는 영상 종류마다 다르다는 것을 수치로 보였다.

FINDING 02 · 내 담당

간 CT의 병목은 모델 크기가 아니었다

ResNet-34 · 50 · WideResNet-50으로 바꿔도 결과가 같았다. 원인은 ImageNet–CT 도메인 차이와 512 → 64 해상도 손실로 좁혀졌다.

FINDING 03

임계값은 검증셋으로 고른다

Fixed · Quantile은 점수 분포가 범위 밖이라 전부 정상으로 판정했다. Adaptive는 모든 도메인에서 안정적이었다.

BACKBONE · ADAPTIVE F1

깊다고 좋아지지 않았다

Brain MRI 0.826 / 0.875 / 0.787 (ResNet-18 / 34 / 50), Liver CT 0.634 / 0.624 / 0.626, Retinal OCT 0.691 / 0.694 / 0.694.
